Nonogram

A two-color 10×10 nonogram (picross). One puzzle per seed; all generated puzzles have unique solutions.

Deploy

Static-site bundle. Three files:

  • index.html — entry HTML, references bundle.js via a relative path.
  • bundle.js — single minified ES2020 bundle, no runtime deps.
  • README.html — this file.

To host: copy dist/ to any static-file host (GitHub Pages, S3, Netlify, plain nginx). Works under any subpath because index.html references bundle.js with no leading slash.

URL parameters

  • ?seed=N — integer seed for puzzle generation (default 1).
  • ?glyph=triangle — render the filled-cell glyph as a triangle instead of a square. Default is square.

Example: index.html?seed=42&glyph=triangle

Controls

  • Title screen: press Space to begin.
  • Mouse — left click: cycle a cell (empty → filled → marked-empty → empty).
  • Mouse — right click: toggle the marked-empty (X) flag on a cell.
  • Arrow keys: move the keyboard cursor.
  • Space (during puzzle): cycle the cell under the cursor.
  • X key: toggle marked-empty on the cell under the cursor.

Win condition

You win when every filled cell in your grid matches the unique solution for that seed. Marked-empty cells are ignored — only the pattern of filled cells matters. The board shows a win indicator once state.won flips to true.
