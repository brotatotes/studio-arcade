Star Battle (1★)

A two-color 8×8 Star Battle puzzle. One puzzle per seed; every generated puzzle has a unique solution.

Rules

  • Place exactly one star in every row.
  • Place exactly one star in every column.
  • Place exactly one star in every region (the 8 pre-baked outlined groups; one star per region).
  • No two stars may touch, even diagonally (king-move adjacency forbidden).
  • A SOLVED panel appears once all four rules are simultaneously satisfied (exactly 8 stars placed).

Controls

  • Title screen: press any key to begin.
  • Arrow keys: move the cursor (clamps to the 8×8 grid).
  • Space: toggle a star on the current cell.
  • X: alias for Space — toggles the current cell.
  • Other keys are ignored. Soft-locks are impossible (toggling is fully reversible).

Visual key

Strict two-color palette: #0a0a0a ink on #e8e4d4 off-white. No greys, no anti-aliasing. Every glyph is composed of palette-colored pixels.

URL parameters

  • ?seed=N — integer seed for puzzle generation (default 1).

What's verified

  • Generator correctness & uniqueness — 1000-seed deterministic verifier; 100% uniqueness on accepted puzzles; ≥40% acceptance rate; tier distribution bars met.
  • Solve correctness — 100 seeds replayed end-to-end via Playwright; each reaches state.won === true after replaying the canonical star placements via cursor + Space.

What's NOT verified

  • Touch / mobile input. Keyboard-driven only.
  • Accessibility / screen readers. Pure canvas; no DOM grid, no ARIA.
  • Cross-browser parity. Verifiers run under Chromium only.
  • Save state. Refreshing resets the puzzle; ?seed=N is the only restoration mechanism.
