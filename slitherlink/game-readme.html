Slitherlink

A two-color 7×7 slitherlink (loop puzzle) on an 8×8 dot lattice. One puzzle per seed; all generated puzzles have unique solutions.

Deploy

Static-site bundle. Three files:

  • index.html — entry HTML, references bundle.js via a relative path.
  • bundle.js — single minified ES2020 bundle, no runtime deps.
  • README.html — this file.

To host: copy dist/ to any static-file host. Works under any subpath because index.html references bundle.js with no leading slash.

URL parameters

  • ?seed=N — integer seed for puzzle generation (default 1).

Rules

The board is a 7×7 grid of cells, with dots at the 8×8 lattice corners. Some cells contain a digit 0, 1, 2, or 3 (the clue); blank cells have no constraint.

Draw a single closed loop along cell edges (segments connecting adjacent dots). The loop must satisfy every clue: a cell with digit k must have exactly k of its 4 edges drawn as part of the loop. The loop may not branch, cross itself, or have any loose ends — every dot it touches has exactly 2 incident drawn edges.

Controls

  • Title screen: press Space or click anywhere to begin.
  • Mouse — left click on an edge: cycle that edge: blank → drawn → X (denial mark) → blank.
  • Arrow keys: move the keyboard cursor between adjacent edges.
  • Tab: flip the cursor orientation between horizontal and vertical edges.
  • Space / Enter: cycle the edge under the cursor.

Edge coordinates

Edges are addressed by canonical strings:

  • h:r:c — the horizontal edge from dot (r,c) to dot (r,c+1). Equivalently: the top edge of cell (r,c), or the bottom edge of cell (r-1,c). Valid range: r ∈ [0..7], c ∈ [0..6].
  • v:r:c — the vertical edge from dot (r,c) to dot (r+1,c). Equivalently: the left edge of cell (r,c), or the right edge of cell (r,c-1). Valid range: r ∈ [0..6], c ∈ [0..7].

The dot lattice is 0-indexed with row 0 at the top and column 0 at the left.

Win condition

You win when the set of drawn edges (ignoring X marks) exactly equals the unique solution's edge set for that seed. X marks (denial marks) are ignored when checking the win — only drawn edges matter. The board shows a SOLVED indicator once state.won flips to true.
