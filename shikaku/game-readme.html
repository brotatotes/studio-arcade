Shikaku

A two-color 10×10 Shikaku (四角に切れ) puzzle. One puzzle per seed; every generated puzzle has a unique solution.

Rules

  • Divide the 10×10 grid into axis-aligned rectangles.
  • Each rectangle must contain exactly one numbered clue cell.
  • The clue's number equals the rectangle's area (in cells).
  • Every cell ends up inside exactly one rectangle (no gaps, no overlaps).
  • A SOLVED panel appears when the board is fully partitioned.

Controls

  • Title screen: press any key to begin.
  • Arrow keys: move the cursor (clamps to the grid).
  • Space (anchor): with no anchor set, mark the current cell as the rectangle anchor.
  • Space (commit): with an anchor set, attempt to commit the rectangle from anchor to cursor (canonicalized). Failed commits leave the anchor in place; successful commits clear it.
  • Escape: cancel the current anchor.
  • X: clear the committed rectangle covering the cursor cell (if any). Always available, so no soft-lock is possible.
  • Other keys are ignored.

Visual conventions

Strict two-color palette: black ink on an off-white background. Every glyph below is rendered with that palette only — no greys, no anti-aliasing.

URL parameters

  • ?seed=N — integer seed for puzzle generation (default 1).

What's verified

  • M0 — Generator + difficulty. 1000-puzzle deterministic verifier; 100% uniqueness on accepted; ≥40% acceptance; DLX search-tree classifier (branch points / backtracks); bars ≥35/30/20/10% easy/medium/hard/expert; 100% no-guess at hard and below.
  • M1 — Solve correctness. 100 seeds replayed end-to-end via Playwright over file://; each reaches state.won === true after replaying the canonical anchor+commit key sequence.
  • M2 — Legibility. Bar B blind vision-judge over 5 seeds with mid-game screenshots (2–3 canonical rectangles committed). Judge restates rules, counts numbered cells (±2), counts completed rectangles (±1), identifies digit value of named clue cells, identifies UI affordances. Pass ≥4/5.
  • M3 — Fuzz + perf. 200 puzzles × 10,000 random keypresses (2,000,000 keys, 4 workers); 0 pageerrors / 0 console errors / 0 state violations. Frame timing across 5 seeds: median ≤16.7 ms (≥60 FPS bar).
  • M4 — HTTP-serve parity. 10 seeds re-solved end-to-end under a real http.server on 127.0.0.1:PORT, not file:// — bundle works as a deployed static asset.

What's NOT verified

  • Touch / mobile input. Keyboard-driven only.
  • Accessibility / screen readers. Pure canvas; no DOM grid, no ARIA.
  • Cross-browser parity. Verifiers run under Chromium only.
  • Save state. Refreshing resets the puzzle; ?seed=N is the only restoration mechanism.
  • Multi-anchor undo. No undo stack across committed rectangles beyond X on the cursor's cell — no global Ctrl+Z, no anchor history.
