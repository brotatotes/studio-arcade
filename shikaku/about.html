Shikaku

Partition the grid into rectangles. Each clue equals its area.

▶ Play Shikaku

About

Shikaku (四角に切れ) — a Nikoli partition puzzle on a 10×10 grid. Divide the grid into axis-aligned rectangles such that each rectangle contains exactly one numbered clue and the number equals the rectangle's area in cells. Every cell ends up inside exactly one rectangle. Tap-tap commit model (anchor → cursor → commit), no drag preview.

How to play

Arrow keys move the cursor. Press Space on an empty cell to set an anchor; press Space again at a different cell to commit a rectangle from anchor to cursor. The rectangle is accepted only if it contains exactly one clue and its area matches that clue. Press X to clear the rectangle covering the cursor cell. Press Escape to cancel a pending anchor. Win when every cell belongs to a committed rectangle.

Features

  • 10×10 partition puzzle
  • Tap-tap commit input model (no drag)
  • Per-commit rectangle validation — invalid commits rejected
  • Unique-solution generation
  • Numbered-clue area constraints
  • Vanilla TypeScript single-bundle build
